# 国家风格图鉴 / 2026-10-23

本轮在原有日韩原帖、28 张参考图和商品目录基础上，增加美国、英国、法国与意大利四个入口，每国三种差异明确的风格路线。国家用于组织服装传统与品牌实践，单品可以跨国搭配；并不把品牌生产地直接当作一种风格的归属。

每种风格包含包包、鞋子、上衣、外套、裤子、首饰、配饰七个槽位。四个服装核心槽位在同国三套之间至少有三项不同，三件外套均不同；包、首饰和配饰可以复用，便于看出同件商品如何改变语境。这里提供的是编辑选择的搭配思路，穿衣时按温度、场合和自身尺寸取舍。

## 页面

`#/catalog/world` 展示全部风格；`#/catalog/world/us`、`/uk`、`/fr`、`/it` 按国家查看，提供三种轮廓与配色对照。`#/catalog/world/:styleId` 打开完整风格页：七类真实商品的搭配板、风格特点、具体选品理由、对应价格与商品入口，以及服装传统和当前系列的资料依据。

风格可以搜索国家、名称、品牌与商品，收藏存入当前浏览器的 `fitgram.worldSaves`。详情支持七种品类筛选。点击商品进入已合并的商品目录、清除旧筛选并定位到商品；商品卡也能回到使用它的各国风格。旧照片与商品的关联仍保留。

## 来源与图片

款名、配色、材质、货号或网站标识分别保留对应商品资料。价格按核验时的原币种记录，未取得价格时保留空值；没有验证含税到手价或大陆配送。图片从官方品牌或零售商页面保存，只等比压缩或转格式。若商品使用品牌真人上身参考，单独以 `imageKind: worn` 标注，不把其当作平铺单品图。发现官网明确说明单品图由 AI 生成或修改时，改选可核对的真人参考或其他商品图。

风格依据是实际查阅的品牌历史、系列或具体商品资料。经典辨识度与当前品牌实践共同作为选品标准，不编造销量、热度名次或社交账号互动。

## 维护与验收

每国资料存于 `assets/research/world-products-{us,uk,fr,it}.json` 和 `world-styles-{us,uk,fr,it}.json`。商品记录沿用原目录结构并标记 `collection: world`；风格每个槽位通过商品 ID 引用，避免再建一组无法对照的示意商品。

`python3 tools/build_catalog.py` 将新商品并入 `catalog-data.js`，将四国风格与出处写入 `world-data.js`。应用保持普通 script 与原生 IIFE，无网络依赖、ES Module 或本地 JSON fetch，支持 file:// 离线查看已保存的图片与资料。

`node tools/check_world.js` 核对四国各三套、84 个品类槽位、商品存在与类别、风格差异、材料与来源。`node tools/check_catalog.js` 检查完整商品目录、唯一实际图片、域名、币种与原有预算；`node tools/check_atlas.js` 和 `check_integrity.js` 继续检查原有照片与原帖档案。
