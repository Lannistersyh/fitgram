# 单品图鉴 / 2026-10-21

新增独立的购买与搭配选品目录：鞋子、裤子、衬衫各 10 款。用户要求真实单品图与可追溯型号，目录图片取自对应品牌官方商品页。搭配建议属于编辑选品，不以男团同款作为销售依据。

## 页面与操作

- 入口：`#/catalog`；三个类别 `#/catalog/shoes`、`#/catalog/pants`、`#/catalog/shirts`；全部 `#/catalog/all`。
- 按品牌、中文款名、原文款名、货号、颜色或标签即时搜索。
- 商品卡显示真实商品图、品牌、型号、货号、颜色、当地官网记录价格；无可靠价格时显示“价格请查看官网”。
- “怎么搭 · 购买前看”展开搭配、试穿重点、库存记录与核验日期。
- 书签加入本地购买清单，按币种分别小计；支持仅看收藏、复制准确款名和货号。收藏存储于 `fitgram.catalogSaves`，不与原帖收藏或服装识别数据混用。
- 三组跨类别搭配可以点图定位到具体款式。手机导航直接提供“单品图鉴”入口，原照片速览保留于桌面与更多菜单。

## 数据与维护

核验记录位于 `assets/research/catalog-{shoes,pants,shirts}.json`，每条保留官方详情、图片 URL、核验日期与当地市场；实际显示的商品图片保存在 `assets/catalog/`，不依赖官网热链成功。原图只作尺寸优化、格式转换，不通过生成或抠图创造商品外观。

使用 `python3 tools/build_catalog.py` 生成 `js/catalog-data.js`；`node tools/check_catalog.js` 验收数量、型号、官方域名、图片、币种与组合引用；`node tools/check_integrity.js` 保持原有穿搭数据验收。

境外官网价格保留原币种。页面明确说明其不是大陆到手价，不含运费税费；链接不保证向大陆发货。图库帮助按货号找货，实时价格、颜色、库存和尺码需在商品页复核。
