## 最终快照

- 真实来源11个：日系5个、韩系6个；8个来源贡献入选造型，3个来源保留在图鉴中。
- 造型48套，原帖永久链接去重40条，原帖code去重40条；不要求48套来自48条不同原帖。
- 48个唯一造型ID与分析键，212个唯一单品ID；全部单品均被造型引用。
- 48张主图均为 `assets/real/` 下实际存在的JPEG照片，文件头有效，实际宽高与数据元信息一致；没有以SVG、HTML响应或另一套示意造型充作真实照片。
- 中文观察为92～118字符；每条均保留原帖、图片序号、图片采集证据及“本站观察”标记。
- 单品证据：36条 `exact`、25条 `brand`、151条 `visual`。
- 官网已核实价格的单品出现31次，对应27个去重TONYWACK官方商品，全部使用KRW原币种。
- 未核实日期20套、未核实实测气温48套、未采集点赞数20套；未知值保留为空或 `unknown`。
- 原帖模拟评论0条、虚构整套预算0条；所有整套预算字段为null。

仅保留主页资料的来源为 `@japan_streetstyle_`、`@nanikajapan`、`@alyxtsu`。这三者不虚构帖子补足数量，仍可从图鉴访问实际公开主页。

## 风格覆盖

标签为本站编辑观察，允许一套有多个标签，因此计数总和大于48：韩系极简16、Y2K复古18、日系工装4、Ivy/Preppy 9、Clean Fit 13、街头廓形23、City Boy 3、Gorpcore 1。

真实样本没有覆盖所有预设风格，也不均匀覆盖温度或场景。不以凑齐“每类至少3套”为理由改写照片含义；All Grey全灰与无性别Archive未被本轮样本可靠归入。

## 重复执行

在项目目录运行：

```sh
node tools/check_integrity.js
```

正常结果输出 `passed: true`，并报告来源数、造型数、去重原帖链接数、证据分布、价格与图片数量、未知值和代码行数。脚本不修改正式数据，也不重新请求官网或Instagram。

报告中的 `browserTabsOpened: 0` 仅表示本次离线构建/验收没有打开浏览器，不代表主任务此前采集公开来源时未使用浏览器。视觉布局、键盘行为、持久化与真实用户操作的结果见 `ACCEPTANCE.md`；静态断言不替代逐图人工判断，也不能保证外部链接未来不变。
