# 潮流历史图集

历史图集是现有衣橱的另一条阅读路径：先看真实的历史图像，再看可观察的轮廓与细节，最后进入当前搭配和单品。它与国家风格、穿搭参考及商品目录共用页面导航和商品收藏，不复制一套独立商品。

首轮共 12 个章节，美英法意各 3 章，6 张历史照片、4 张馆藏实物摄影、2 张品牌档案。25 条出处记录支撑图像与历史背景；关联 16 种风格与 35 件当前商品，形成 36 次逐件参考。

入口为 `#/catalog/history`；国家入口为 `#/catalog/history/us`、`uk`、`fr`、`it`；章节通过稳定 ID 直达。网页支持讨论年代、国家、关键词和已收藏章节筛选，详情支持全图放大、来源阅读与按年代翻章。

## 图像与年代

图片保留完整画面，仅等比缩放和 JPEG 压缩。卡片和详情分别显示以下类型：历史照片、馆藏实物、品牌档案。馆藏服装的制作年代不是图片拍摄时间；品牌档案中的历史衣物也可能由机构近年重新拍摄。每章的 `imageDate` 按来源的原意说明，章节的 `year` / `endYear` 只用于组织讨论年代和筛选。

页面不以一张照片证明整个国家、群体或年代的穿衣方式。跨文化的风格流动和同时存在的传统可以并列讨论；今天的风格标签不自动倒推为历史人物的自我认同，也不自动代表某种风格的发明时间。

每张图保留图片所在页面、实际图片 URL、署名、权利说明及本地文件 SHA-256。来源未给出的摄影师和拍摄日期不补造。图像中的人物仅在原始机构明确说明身份时命名。页面的可见细节和搭配建议是本站编辑观察，与机构的事实说明分别表述。

## 与今天的衣橱连接

每章关联当前的国家风格，并选择三件已有商品作今天的参考。来源档案没有直接证据时，当前商品不标为历史原物同款，也不因看起来相像而确认品牌。选择理由分别记录在 `productNotes`；商品的原始图片、核验日期、价格币种和渠道状态继续使用原有目录。

从风格页可回到对应历史章节，从商品卡也可反向查看有关的历史线索。点击历史章节中的当前商品会定位到共享目录里的具体卡片，可以查看已有材质资料、图片出处和购买记录。

## 数据维护

事实和图像记录分别位于 `assets/research/history-us-uk.json` 与 `assets/research/history-fr-it.json`；本地图片位于 `assets/history/`。每条来源用 `supports` 说明它具体支持什么事实，图片出处也列入来源列表。

修改来源记录后执行：

```sh
python3 tools/build_history.py
node tools/check_history.js
node tools/check_integrity.js
```

`js/history-data.js` 是生成结果，以普通脚本赋值给 `window.FITGRAM_HISTORY`，浏览时不 fetch 本地 JSON，保持 file:// 与离线可用。`js/history.js` / `css/history.css` 负责展示；商品与国家风格仍由既有生成脚本维护。
